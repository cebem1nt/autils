# autils - audio utils

A repository with different audio utilities/scripts written in python using ffmpeg

## List

| Script  | Description | Example usage  |
|---------|-------------|----------------|
|`cuecut` | Split audio files based on it's `.cue`, tag with available info automatically | `cuecut album.cue cover.jpg`  | 
|`cover`  | Add cover / album art to given files | `cover *.mp3 -c cover.jpg` |

You can use -h for each script in order to get additional info/help
